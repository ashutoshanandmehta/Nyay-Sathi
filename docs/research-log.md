## Source ingestion run

`python -m app.rag.ingest --json` fetched and hashed 18 official documents and created 607 page-located passages. Two discovery/register pages were deliberately skipped because a search index is not itself claim-supporting text. The Department-hosted Act copy replaced the earlier timed-out India Code download URL while retaining the source's stable ID. The 607 full-source passages combine with 14 curated provision-level excerpts for 621 searchable passages. `python -m scripts.rebuild_legal_index` then synchronised all 621 entries into persistent Chroma, removed stale vector IDs, and returned corpus version `956293ec74ee`. The app does not claim this is every applicable rule, a consolidated authoritative text, or proof of case-specific applicability.

The structured application guidance in `data/knowledge/consumer_support_v1.json` was newly written for this project from the sources above. It is versioned separately from legal passages, clearly marked pending review by an Indian lawyer, and is not treated as legal authority. Apart from the two attributed implementation-pattern adaptations above, no external repository code, templates, datasets, model weights, or assets were reused.
